📖Dify — 开源 LLM 应用开发平台

Dify 是一个开源的 LLM（大语言模型）应用开发平台，帮助开发者和企业快速构建 AI 原生应用。它提供从 Prompt 编排到模型部署、从 Agent 编排到 RAG 检索增强的全流程工具链。

Dify 支持 GPT、Claude、通义千问、文心一言等多种主流模型接入，用户可以通过可视化界面编排 AI 工作流，无需从零编写代码。截至 2025 年，Dify 在 GitHub 上获得超过 5 万 Star，是开源 AI 应用开发领域的标杆项目。

✨核心特色

  • 可视化 Workflow 编排，拖拽式构建 AI 流程
  • RAG 引擎：支持多种文档格式和向量数据库
  • Agent 能力：支持函数调用、工具集成
  • 多模型支持：OpenAI / Claude / 通义 / 文心等
  • 开源可私有化部署，数据完全可控
  • 提供 API 和 SDK，方便二次开发

🎯典型应用场景

  • 企业内部知识库问答系统
  • 客户服务 Chatbot
  • 文档智能分析与摘要
  • AI 工作流自动化
  • 多模型对比与评测平台
