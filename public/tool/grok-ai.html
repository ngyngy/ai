📖Grok — xAI 的 AI 对话助手

Grok 是 Elon Musk 旗下 xAI 公司开发的 AI 对话助手，以实时信息获取和幽默风格著称。Grok 通过 X（原 Twitter）平台获取实时信息，能够回答关于最新事件的问题。

Grok 的定位是"有趣的 AI"——它以幽默和不循规蹈矩的风格区别于 ChatGPT 和 Claude。Grok 还提供图像生成、代码编写、数学推理等功能，并深度集成到 X 平台中，X Premium+ 用户可直接使用。

✨核心特色

  • 实时信息：通过 X 平台获取最新资讯
  • 幽默风格：有趣且不拘一格的回答
  • 图像生成：内置 Flux 模型文生图
  • 代码编写与数学推理
  • 多模态：支持图片理解和分析
  • Fun Mode / Regular Mode 切换

🎯典型应用场景

  • 获取最新新闻和事件信息
  • 日常问答与创意写作
  • 编程辅助
  • 社交媒体内容创作
  • 图片生成和编辑

💰收费模式

X Premium+$16/月X 平台内使用 Grok
独立版免费有限次数体验
SuperGrok$30/月无限使用 + DeepSearch

💡使用技巧

  • 实时信息查询是 Grok 的核心优势
  • Fun Mode 可获得更有趣的回答
  • 图像生成无严格内容审查限制
  • 结合 X 平台数据可获得更准确的事件信息
