📖OpenClaw — 开源 AI Agent 框架

OpenClaw 是一个开源的 AI Agent 框架项目，致力于为开发者提供灵活、可扩展的智能体开发工具。它支持自定义工具集成、多模型接入、工作流编排等核心能力，帮助开发者快速构建各类 AI Agent 应用。
